怎么点

  1. 左边名单现在列出这台电脑上所有的仓库。v4-plus 没人在线：写一行「没人在线」。
  2. 每个仓库最下面有一个「＋ 加 agent」。点它：按钮变成「正在打开 …」，几秒后新的人出现在名单和城里，按钮回到原样。
  3. 仓库没有总督（v4-plus）→ 新的是 Manager（总督）。已经有总督（auto-pipeline、v4-pospro）→ 新的是 Helper。不用选。
  4. 上面选「电脑太忙 / 打开失败 / 文件夹不见了 / 开了但没上线 / 没有 Orca」，再点按钮（或点 ▶ 重放），看每一种情况。
  5. 「▶ 重放：双击」：连点两下，只开一个。
  6. shop-api 是别的成员的仓库，不在这台电脑上：没有按钮。

我先按默认做（有意见就说）

  • 按钮的各种状态都显示在名单里、那个仓库的下面，不弹窗。
  • 「正在打开」时按钮点不动；服务器对同一个仓库一次只开一个。
  • 模型、effort、权限模式都读那个仓库自己的 agent.conf（跟现在派任务一样）。
  • 「没人在线」的仓库在城里的小岛不变：只是名单里多一组。
  • 收起的仓库（点标题收起）不显示按钮，展开才有。
  • 名单最上面的「在线 N」不变：只数在干活的人。
  • 这次只管本机的页面。云端的城市页面先没有这个按钮（以后另一个任务）。
